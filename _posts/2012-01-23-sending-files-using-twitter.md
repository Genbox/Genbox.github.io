A user of Twitter tried [an experiment](https://pastebin.com/1pxubqfw) where he uploaded an image of
21436 bytes to Twitter by base64 encoding the file and posting it in 153 tweets (due to the tweet
length limit of 140 characters).

I extracted [the data](https://twitter.com/#%21/Justatest2099) from Twitter and combined it into the
image as seen below:

![Guy Fawkes mask image reconstructed from data sent through Twitter posts.](/assets/images/posts/5afb1066ec120bc26512.jpg){width="170" height="240" loading="lazy" decoding="async"}

It seems there is an error in the image, but the experiment and the question it poses are still
valid.
